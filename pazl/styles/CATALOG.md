# Style catalog / roadmap

Implemented (YAML + macros): generic, greek, roman, romanesque, gothic, renaissance, baroque, classicism,
russian_orthodox, russian_wooden, lithuanian, german_fachwerk, medieval_castle, dugout, soviet_panel,
stalinist, constructivism, modern, egyptian, mesopotamian, mesoamerican, byzantine, caucasian, ottoman, persian,
moorish, mughal, hindu, chinese, japanese, scandinavian, dutch, victorian, alpine, art_deco, brutalism, industrial,
military.
Game styles (with sub-styles): blocky_toy, voxel, fantasy_rpg, cyberpunk, post_apocalyptic, cartoon, scifi.

Next packs (same pattern: YAML with materials/defaults/tips + optional macro + missing generators):
- Ancient: minoan, etruscan, persian achaemenid (apadana), nabataean rock-cut facades.
- Balkan / East: bulgarian, serbian (Morava school), romanian (painted monasteries), ukrainian/polish wooden churches.
- Asia: korean hanok, thai (prang, layered roofs), khmer (Angkor towers), tibetan (dzong), javanese (candi).
- Americas: pueblo adobe, colonial spanish missions, american craftsman, prairie style, log cabin.
- Europe: norman, tudor, georgian, gothic revival, art nouveau, neo-russian (pseudo-russian), swedish red farmhouses.
- 20th c.: bauhaus, post-modern, deconstructivism, hi-tech; infrastructure (bridges, stations, lighthouses, windmills,
  watermills, hangars, gas holders).
- Fantasy & sci-fi: elven, dwarven, steampunk, cyberpunk megablocks, space colonies.
