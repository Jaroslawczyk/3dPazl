Клик — выбрать. Элементы вложены по тому, к чему прикреплены.

    Сборщик

    Выкл. — каждый кирпич остаётся полным кубом (грани на гранях): тяжелее, но каждый кирпич можно сделать отдельным объектом.

    Двери

    Клик по двери в сцене открывает её. В экспорте каждая створка — свой узел с точкой петли и углом открытия (файл .objects.json) — для анимации в игре.

    Разрушаемость

    Больше кусков — реалистичнее, но тяжелее для игры. В экспорте каждый кусок — отдельный объект с центром масс и объёмом (для физики), места разлома — материал «rubble».
