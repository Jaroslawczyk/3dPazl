# 3dPazl — конструктор 3D‑зданий для ИИ и человека

Параметрическая библиотека элементов зданий разных эпох и культур + сборщик, который сваривает всё в один
**замкнутый (watertight) меш без щелей**, проверяет его со всех сторон и экспортирует в игры.
ИИ (Claude Code, Cursor и любые другие) управляет программой через **MCP** или **HTTP API**,
а вы в окне программы смотрите, как собирается модель, двигаете элементы руками и правите параметры.

## Запуск
```bash
start.bat
```
Первый запуск сам создаст `.venv` и поставит зависимости. Откроется окно программы.
Другие варианты: `.venv\Scripts\python -m pazl --browser` (в браузере), `.venv\Scripts\python -m pazl.server` (без окна).

## Подключение ИИ
- **Claude Code**: `.mcp.json` уже лежит в проекте — откройте Claude Code в этой папке, сервер `pazl` подключится.
- **Cursor**: `.cursor/mcp.json` уже лежит в проекте.
- **Любой другой ИИ / скрипт**: HTTP `http://127.0.0.1:8765/api/...`, заголовок `X-Agent: имя`. Описание — `docs/AI_GUIDE.md`
  (его же отдаёт `GET /api/guide`).
Если программа не запущена, MCP‑сервер запустит её сам (окно). `PAZL_HEADLESS=1` — без окна.
- **Чат прямо в программе** (вкладка «💬 Чат с ИИ» внизу): тот же набор инструментов, что у MCP. ИИ на выбор:
  Claude (Anthropic API, ключ), Claude Code (локальный `claude`, по подписке), OpenAI, Gemini, DeepSeek, OpenRouter,
  Groq, Mistral, xAI, Ollama / LM Studio (локально) или любой OpenAI‑совместимый URL. Ключи хранятся только
  на этом компьютере в `chat_settings.json`.

## Как это устроено
- **Рецепт** (JSON) — источник правды: список элементов с параметрами и привязками к **якорям**
  (`main:front`, `main:top`, `roof:ridge` …). Окно ставится в фасад, крыша — на верх стен, поэтому ничего не «летает».
- **Стили** (`pazl/styles/*.yaml`) — материалы и пропорции эпохи: античная Греция, Рим, романика, готика, ренессанс,
  барокко, классицизм, древнерусская/православная, русская деревянная (изба), литовская, немецкий фахверк,
  средневековая каменная (замки), землянки, советский панельный (серии 1‑464, 1‑447, 121, П‑44, II‑18),
  сталинский ампир, конструктивизм, современный, а также Египет, Месопотамия, майя/ацтеки, Византия,
  армянская/грузинская, османская, персидская/среднеазиатская, мавританская, могольская, индуистская, китайская,
  японская, скандинавская, голландская/ганзейская, викторианская, альпийская, ар-деко, брутализм, промышленная,
  военная (38 стилей).
- **Элементы** (~65): объёмы, стены, башни, срубы, лестницы, окна всех форм (прямоугольные, арочные, стрельчатые,
  розы, подковообразные, ленточные…), двери‑порталы, крыши 17 типов, купола (луковица, шлем, барочный),
  шпили/шатры, колонны всех ордеров, портики, карнизы, зубцы, контрфорсы и аркбутаны, фахверк, швы панелей,
  балконы/лоджии, навесы, витражи, мозаики/фрески/иконы, заборы, примитивы для любых нестандартных форм.
- **Макросы** — 39 целых зданий за одну строку (собор, храм, изба, хрущёвка, замок, небоскрёб, палаццо, сталинка,
  пирамиды, мечети, Тадж-Махал, пагода, ставкирка, канальные дома, викторианский дом, завод, ДОТ…),
  которые затем правятся поэлементно (`b/roof`, `b/win_f`) или разбираются на обычные элементы.
- **Проверка**: замкнутость по рёбрам, висящие и несвязанные части с id элементов; рендер 12 ракурсов
  (4 стороны, 4 изометрии, сверху, снизу, 2 разреза) одним листом — проблемы подсвечены красным.
- **Детализация**: «Реализм» или «Low‑poly» (меньше сегментов, без мелкого декора). Оптимизация треугольников
  без потери формы + LOD‑экспорт с заданным числом треугольников.

## Новое в 0.3
- **Этажи и любые размеры**: число, диапазон (`{"rand":[3,7]}`) или микс (`{"mix":[5,9]}` — у каждой секции/дома своя этажность).
  В панели свойств у этажей переключатель «число / диапазон / микс», кнопка «🎲 Сид» перебрасывает случайности.
- **Микс стилей**: второй селектор стиля в шапке или `"style": "gothic+russian_orthodox"` у любого элемента.
- **Библиотека по эпохам и территориям**: фильтры «Древность … Современность» и регионы.
- **Фасады**: в свойствах блока — «Фасад: окна на стороне» (заменить стиль окон или убрать окна с выбранной стороны).
- **Покраска**: вручную (цвета стен/крыши/декора/рам/дверей/цоколя) или «🎲 Покрасить» по палитре стиля.
  Low-poly — плоские цвета без текстур, Реализм — PBR-текстуры с подкраской.
- **Интерьеры за окнами**: картинка комнаты за каждым стеклом, в окне — с 3D-иллюзией глубины (interior mapping).
- **Декали**: граффити, грязь, копоть, мох, ржавчина, подтёки, трещины, облезлая краска, плакаты; «🧱 Состарить» — всё сразу.
- **Интерьер**: «🏠 Интерьер» — комнаты, коридоры, двери, лестницы (винтовые до 1500 г.), лифты (с 1880 г. в высоких домах),
  мебель; план этажей в свойствах; свои планы через параметр `plan`. Ползунок «Срез» — заглянуть внутрь.
- **Проверка**: 16 ракурсов (+4 с уровня земли и план-разрез), поиск мерцающих поверхностей (z-fighting),
  наложенных декалей и вырожденных треугольников.

## Текстуры
Меню **🎨 Текстуры → Скачать PBR** загружает бесплатные CC0-паки ambientCG (цвет, нормали, шероховатость, AO, высота) в `textures/library`. Пункт «Промпты» (или `texture_manifest`) создаёт `projects/<проект>/textures/PROMPTS.md` и `manifest.json`:
для каждого материала — готовый промпт, имя файла и папка. Дайте промпты Cursor/другой ИИ, положите PNG
(`<материал>_albedo.png`, опционально `_normal`, `_roughness`) в указанную папку — включите «Цельная» и/или
экспортируйте: текстуры применятся автоматически (UV — box‑проекция в метрах, тайлинг из библиотеки).
Общие текстуры лежат в `textures/library` и работают во всех проектах.

## Интерфейс
Слева — дерево здания, библиотека элементов, стили. Центр — 3D (Q выбор, W двигать, E вращать, F приблизить,
Del удалить, Ctrl+Z/Y). Справа — параметры выбранного элемента. Снизу — лента работы ИИ, отчёт проверки, скриншоты.
Галочка «Камера ИИ» — камера повторяет ракурсы, с которых ИИ проверяет модель.
