# Промпт для Cursor (Grok): набор бесшовных PBR-текстур

Скопируй всё ниже линии целиком в Cursor.

---

## ЗАДАЧА

Напиши Python-скрипт `scripts/make_tiles.py` (только `numpy`, `Pillow`, `scipy` — никаких внешних картинок и нейросетей), который **процедурно генерирует** набор **бесшовных (seamless, tileable) PBR-текстур** для 3D-сцены. Запусти его, сгенерируй всё в `assets/tiles/<категория>/<имя>/`, затем запусти проверку бесшовности и исправь то, что не прошло.

## ФОРМАТ ВЫХОДА (для КАЖДОЙ текстуры)

Папка `assets/tiles/<категория>/<имя>/`, в ней PNG одного размера:

| файл | что это | формат |
|---|---|---|
| `albedo.png` | базовый цвет БЕЗ теней и бликов | RGB 8 bit, sRGB |
| `height.png` | карта высот (heightmap), белое = выше | серый 16 bit (если Pillow не умеет — 8 bit L) |
| `normal.png` | normal map, OpenGL-стиль (+Y вверх), строится из height по Собелю, strength ~2–4 | RGB, фон (128,128,255) |
| `ao.png` | ambient occlusion — тени в щелях/стыках/порах, считается из height (blur разницы: `blur(height) - height`, clip, нормализация) | серый 8 bit |
| `roughness.png` | шероховатость: 0 = зеркало, 255 = матовое | серый 8 bit |
| `metallic.png` | 0 или 255 (металл/не металл), без середины, кроме ржавчины/краски | серый 8 bit |
| `preview.png` | 3×3 тайлинг albedo для глаз | RGB |

Размер: **1024×1024** по умолчанию, ключ `--size 2048` для крупных. Размер всегда степень двойки, квадрат.

## ГЛАВНОЕ ТРЕБОВАНИЕ: ШВОВ НЕ ДОЛЖНО БЫТЬ

Текстуры стыкуются друг с другом как пазл: правый край = левый, верх = низ, и 3×3 мозаика не показывает линий.

Как этого добиться (обязательно):
1. **Весь шум — периодический.** Пиши свой `tileable_noise(size, scale, seed)`: либо value/gradient noise с индексами `% period`, либо фильтрация белого шума в FFT (`np.fft`) — он периодичен по построению. Складывай октавы fBm, у каждой октавы целая частота (`period = 2**k`), чтобы период делил размер.
2. **Все примитивы заворачиваются по модулю.** Доски, кирпичи, плитки, пятна, трещины, царапины, разметка: координаты берутся `% size`; если объект вылезает за край, рисуй его ещё раз со сдвигом на ±size (или `np.roll`).
3. **Число элементов в ряду — целое.** 8 досок на тайл, 6 кирпичей на ряд, 4 плитки — так, чтобы паттерн сходился ровно на краю. Никаких «примерно».
4. **Запрещено**: рисовать как есть, а потом «размывать шов» или клонировать край. Шов должен быть невозможен по построению.
5. **Виньетка и градиент яркости по тайлу запрещены** (самая частая причина видимого повтора). Крупные пятна яркости — только тайлящийся шум, амплитуда ≤ 8–10 %.
6. **Блики и тени не запекать в albedo.** Объём даёт normal/AO, свет даёт движок.

## ПРОВЕРКА (обязательно запустить)

Напиши `scripts/check_tiles.py`: для каждого PNG в `assets/tiles/**`
- склей 2×2 и посчитай средний модуль разницы соседних пикселей на швах (по вертикали и горизонтали) и сравни со средней разницей соседних пикселей внутри тайла;
- если шов > 1.5× внутренней разницы — **FAIL**, вывести имя;
- для normal.png проверь, что вектора нормализованы (|n|≈1) и по краям нет скачка;
- сохрани `assets/tiles/_contact_sheet.png` — сетка 3×3 каждого `preview.png` с подписью.
Скрипт возвращает код 1 при любом FAIL. Исправляй генератор, пока всё не станет PASS.

## РЕАЛЬНЫЕ РАЗМЕРЫ (масштаб)

В `assets/tiles/manifest.json` для каждой текстуры запиши `tile_meters` — сколько метров реального мира покрывает ОДИН тайл (по стороне), и `px_per_m = size / tile_meters`. Детали рисуй именно в этом масштабе (доска шириной 14 см, кирпич 21×6.5 см и т.д. — считай пиксели через `px_per_m`, а не «на глаз»).

## СПИСОК ТЕКСТУР

Каждая — отдельная функция-генератор с `seed`, параметрами цвета и вариантами (`_v1.._v3`, разные seed, одинаковые цвета/масштаб — чтобы можно было смешивать соседние плитки без повтора).

### 1. Крыши (`roof`) — тайл 1.0 м
- `roof_clay_tile` — красная/оранжевая глиняная черепица, волнистые ряды (синус по X, смещение рядов на пол-черепицы), height — валик волны, AO — щели между рядами, лёгкий мох в щелях. Шаг 0.2 м, 5 рядов на тайл.
- `roof_shingle_dark` — битумная плитка-шингл серо-чёрная, ряды со смещением, прямоугольные язычки 0.33×0.17 м, зерно гравия.
- `roof_metal_standing_seam` — металлический фальц: вертикальные швы каждые 0.5 м, 2 шва на тайл, лёгкая волна листов.
- `roof_thatch` — солома: тысячи коротких жёлто-бурых волокон по диагонали, толстый height.
- `roof_slate` — сланец: неровные тёмно-серые плитки, разный оттенок у каждой.
- `roof_wood_shake` — деревянная дранка, ряды, цвет от серого до коричневого.

### 2. Стены (`wall`) — тайл 1.0–2.0 м
- `wall_brick_red` — кирпич 0.21×0.065 м, шов 1 см, перевязка «в полкирпича», у каждого кирпича свой оттенок и пятна, шов светлее и ниже по height. Кирпичей по целому числу в ряду.
- `wall_brick_old` — то же, но выщербленный, часть кирпичей темнее, потёки.
- `wall_stucco_white` — штукатурка (зерно + лёгкие волны), 2 варианта: белая и песочная.
- `wall_concrete` — бетон: поры, разводы, швы опалубки панелей 1×1 м, отверстия под анкеры по углам панелей.
- `wall_stone_blocks` — тёсаный камень разного размера (раскладка «кладка в разбежку»), обязательно замкнутая по краям.
- `wall_cobble_rubble` — бутовый камень.
- `wall_wood_planks_vertical` — вагонка/доска вертикально (см. дерево).
- `wall_tiles_ceramic` — кафель 0.2×0.2 м, шов 2 мм, глянец (низкий roughness на плитке, высокий в шве).
- `wall_siding_vinyl` — горизонтальный сайдинг, шаг 0.2 м, тонкая тень под каждой панелью.

### 3. Земля / дороги (`ground`) — тайл 2.0 м
- `asphalt_clean` — асфальт: тёмно-серая основа, зерно щебёнки (мелкие светлые/тёмные точки), еле заметные пятна.
- `asphalt_worn` — то же + трещины (тайлящиеся ветвящиеся линии, wrap по краям), заплатки, масляные пятна (низкий roughness).
- `asphalt_wet` — roughness низкий, albedo темнее.
- `concrete_slab_sidewalk` — тротуарная плита 1×1 м со швами.
- `paving_stone_grey` — брусчатка 0.2×0.1 м в «ёлочку».
- `cobblestone` — булыжник, неровный, глубокий height.
- `gravel`, `sand`, `dirt_dry`, `mud`, `grass_short`, `grass_dry`, `snow`, `forest_floor` (листья, хвоя, ветки).
- `curb_stone` — бордюр (полоса вдоль тайла).

### 4. Дорожная разметка (`road_marking`) — тайл 4.0 м, ПОВЕРХ асфальта
Это **не** полная текстура, а набор тайлов с альфа-каналом `albedo.png` в RGBA + height + roughness. Все совместимы по краям с `asphalt_*` (тот же размер/масштаб) и стыкуются друг с другом по линии посередине/по краю, чтобы линия шла непрерывно при повторе по одной оси.
- `mark_center_dashed_white` — прерывистая белая, штрих 3 м / пропуск 9 м, ширина 12 см (по ГОСТ/EU стилю).
- `mark_center_solid_yellow` — сплошная жёлтая.
- `mark_double_solid_yellow` — двойная сплошная.
- `mark_edge_solid_white` — краевая линия.
- `mark_crosswalk_zebra` — «зебра»: полосы 0.5 м шириной, шаг 1 м.
- `mark_stop_line` — стоп-линия 0.4 м.
- `mark_arrow_straight / left / right` — стрелки (векторные формы в мировых метрах).
- `mark_parking_slot` — парковочная полоса под 90° (2.5×5 м).
- Износ: краска стёрта шумом (маска), через неё проступает асфальт, края слегка неровные. Wrap по периодической оси обязателен.

### 5. Дерево (`wood`) — тайл 1.0 м
- `wood_planks_horizontal` — доски шириной 14 см, длина 1 м (целое число на тайл — 7 рядов; стыки торцов со сдвигом, каждый ряд с разным seed), волокна вдоль доски (анизотропный растянутый шум), сучки (ровные эллипсы со спиральным ореолом волокон), зазоры между досками тёмные и низкие по height.
- `wood_planks_vertical`, `wood_planks_diagonal`, `wood_parquet_herringbone` (паркет «ёлочка» 0.07×0.28 м), `wood_parquet_strip`.
- `wood_oak_light`, `wood_walnut_dark`, `wood_pine_knotty`, `wood_birch_pale`, `wood_weathered_grey` (серое выветренное: трещины вдоль волокон), `wood_painted_white`, `wood_painted_red` (краска облезает: маска шума → под ней древесина).
- `wood_log_bark` — кора ствола (вертикальные борозды).
- `wood_plywood`, `wood_osb` — фанера (слои/пятна), OSB (хаотичные щепки).
- `wood_crate`, `wood_fence_boards`, `wood_deck`.

### 6. Металл (`metal`) — тайл 0.5–1.0 м
- `metal_brushed_steel` — шлифованная сталь: сверхтонкие линии вдоль одной оси (анизотропный шум 1×512), metallic=255, roughness 60–90.
- `metal_diamond_plate` — рифлёный лист «ёлочкой» (ромбы 2.5×1 см, чередование поворота 90° в шахматном порядке), высокий height.
- `metal_corrugated` — профнастил (волна синус, 7.5 волн на 1 м), лёгкая ржавчина по краям волн.
- `metal_rust_heavy` — ржавчина: оранжево-коричневая, metallic падает до 0 в рыжих зонах, roughness высокий.
- `metal_painted_chipped` — крашеный металл, краска сколота (маска), под ней голая сталь.
- `metal_galvanized` — оцинковка с кристаллическим узором (Voronoi-«цветы»).
- `metal_copper_oxidized` — медь с зелёной патиной.
- `metal_gold_brass`, `metal_chrome` (идеально гладкий, roughness 10), `metal_cast_iron` (шершавый, поры), `metal_rivets_panel` (панели с заклёпками шаг 10 см), `metal_grate` (решётка; альфа-прорези), `metal_perforated`.

### 7. Карбон и техно (`tech`) — тайл 0.1–0.25 м
- `carbon_twill_2x2` — карбон саржа 2×2: пересечения жгутов, каждый жгут — тонкие нити (шум вдоль), диагональное плетение, чёрно-серый albedo, лак (roughness 25) + лёгкий анизотропный блик.
- `carbon_plain_weave`, `carbon_forged` (рубленый карбон — хаотичные чипы), `kevlar_yellow`.
- `fabric_canvas`, `fabric_denim`, `fabric_leather` (поры), `leather_perforated`, `rubber_tread`, `rubber_floor_dots` (резиновое покрытие с кружками), `plastic_matte_abs`, `plastic_grained`, `foam_sponge`.
- `glass_frosted`, `glass_scratched` (для окон; roughness/альфа).

### 8. Прочее (`misc`) — тайл 1.0 м
`tile_floor_checker`, `tile_floor_terrazzo`, `marble_white`, `marble_black_gold`, `granite_grey`, `carpet_grey`, `cardboard`, `paper_rough`, `plaster_cracked`, `lava_cracked` (emissive.png), `ice`, `bark_birch`, `moss`, `ivy_leaves`.

## ТЕХНИЧЕСКИЕ ПРАВИЛА КОДА

- Один модуль-ядро `scripts/tilelib.py`: `tileable_noise`, `fbm`, `voronoi_wrap` (расстояния до точек с учётом 9 копий для wrap), `height_to_normal`, `height_to_ao`, `save_set(name, albedo, height, rough, metal, ...)`, `tile3x3`. Генераторы категорий — импорты из него.
- Детерминизм: `np.random.default_rng(seed)`, никакого глобального `random`.
- Вся математика векторная (numpy), без циклов по пикселям; цикл допустим только по объектам (доска, кирпич, трещина).
- `python scripts/make_tiles.py --only wood,metal --size 1024` — запуск по категориям; `--list` показывает список.
- Albedo-диапазон физически правдоподобный: ни один albedo не темнее 30/255 и не ярче 240/255 (кроме чистой белой краски/снега), металл — яркий albedo = цвет металла, неметалл — не чистый чёрный/белый.
- Всё в `assets/tiles/` — реально записанные PNG, не только код. По окончании выведи таблицу: имя, размер, tile_meters, PASS/FAIL шва.

## КРИТЕРИЙ «ГОТОВО»

1. `python scripts/check_tiles.py` → exit 0, ни одного FAIL.
2. В `_contact_sheet.png` в мозаике 3×3 нет ни линий шва, ни очевидного повторяющегося «пятна-маяка».
3. Любую текстуру можно положить 10×10 на плоскость, и выглядит как цельная поверхность.
4. `manifest.json` содержит для каждой: путь, категория, size, tile_meters, px_per_m, список карт.

Начни с ядра (`tilelib.py` + проверка), сделай и проверь **одну** текстуру (кирпич), покажи 3×3 превью, и только потом генерируй остальные категории.
